# Glossary

Terms are added as topics are published.

| Term | Meaning |
|---|---|
| **Interpreter** | The program (`python`) that reads your code and runs it. |
| **REPL** | Read-eval-print loop. The interactive prompt that starts when you run `python` alone. |
| **Script** | A `.py` file you run with `python file.py` or `uv run file.py`. |
| **Traceback** | The report Python prints when an error stops your program. Read it from the bottom. |
| **Comment** | Text after `#` that Python ignores. |
| **Virtual environment** | A project-private folder of installed packages, so projects do not clash. `uv` creates it for you in `.venv`. |
| **Truthy / falsy** | How a value behaves in an `if`. Falsy: `False`, `None`, zero, empty string and empty containers. Everything else is truthy. |
| **Expression** | Code that produces a value, such as `2 + 3`. |
| **Statement** | Code that does something, such as `if`, `for` or an assignment. |
| **Pattern (in `match`)** | The shape after `case` that the subject is compared with. It can also bind names. |
