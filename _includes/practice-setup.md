## One-time setup

You need [uv](https://docs.astral.sh/uv/) (see the Getting started topic) and Git.

```bash
git clone https://github.com/luodonghua/PythonProgrammingLanguage.git
cd PythonProgrammingLanguage
uv sync            # installs Python 3.14+ and pytest into .venv
```

Each assignment folder holds a `starter.py` and a test file. Edit `starter.py`, then run the tests for that folder. A test failure message tells you what is still missing.
